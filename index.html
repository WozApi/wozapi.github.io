WOZ API

Eén REST-endpoint dat de WOZ-waarde, de BAG-adresgegevens, het WOZ-object en de kadastrale percelen van een Nederlands adres teruggeeft. Deze site is de technische documentatie; het product, de prijzen en een account staan op woz-api.nl.

Wat de API teruggeeft

Je stuurt een adres, je krijgt vier soorten gegevens in één JSON-respons terug. Dat is het verschil met de losse basisregistraties, waar je adres, waarde en perceel bij drie bronnen apart moet ophalen en zelf koppelen.

VeldWat erin zit
bagGestandaardiseerd adres met BAG-identificaties (nummeraanduiding, adresseerbaar object)
wozObjectWOZ-objectnummer en grondoppervlakte
wozAlle bekende vastgestelde waarden, met de peildatum per waarde
percelenKadastrale percelen met oppervlakte, optioneel met grenzen als GeoJSON

Een call in drie regels

curl "https://woz-api.nl/Api/Adres?adres=Spuistraat%2036C,%201012TT%20Amsterdam" \
  -H "X-Api-Key: JOUW_API_KEY"

Het antwoord, ingekort:

{
  "adres": "Spuistraat 36C, 1012TT Amsterdam",
  "bag": {
    "nummeraanduidingId": "0363200000418472",
    "straatnaam": "Spuistraat",
    "huisnummer": 36,
    "postcode": "1012TT",
    "woonplaatsnaam": "Amsterdam"
  },
  "wozObject": { "wozobjectnummer": 36300285811 },
  "percelen": [
    { "aanduiding": "ASD04 F 1145", "oppervlakteM2": 92 }
  ],
  "woz": [
    { "peildatum": "2025-01-01", "vastgesteldeWaarde": 662000 }
  ]
}
Let op de veldnaam. De reeks waarden heet woz, niet wozWaarden. Elk element heeft peildatum en vastgesteldeWaarde. Een adres heeft meestal meerdere peildata, oplopend van oud naar nieuw.

Wie deze API wel en niet nodig heeft

Het is eerlijker om dat vooraf te zeggen dan achteraf.

  • Wel: je bouwt software die per adres een WOZ-waarde nodig heeft, in proptech, fintech, makelaardij, notariaat of belastingadvies, en je wilt geen aansluittraject.
  • Niet: je hebt een wettelijke taak met WOZ-gegevens. Dan kun je zelf op de Landelijke Voorziening WOZ aansluiten, en dat is gratis. Zie wie mag aansluiten op de LV WOZ.
  • Niet: je wilt alleen adressen valideren of verrijken met bouwjaar en oppervlakte. Dat kan gratis via de open BAG op PDOK.

Een sleutel aanvragen

Een account op woz-api.nl is gratis en geeft 10 credits. 1 credit is 1 uniek adres; hetzelfde adres binnen 7 dagen opnieuw opvragen kost geen extra credit. De prijzen per credit staan publiek.
